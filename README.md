
# University Projects

A collection of academic projects developed during my studies at the Department of Computer Science and Engineering, University of Ioannina.

## Projects

### 1. [Food Hazard Detection](Food-Hazard-Detection/)
An NLP project developed for a Kaggle competition, focused on classifying food recall reports using machine learning techniques.

**Technologies:** Python, scikit-learn, NLP, TF-IDF

### 2. [Machine Learning Course Projects](Machine-Learning-Course/)
Two projects exploring image classification, dimensionality reduction, and clustering using traditional machine learning and deep learning methods.

**Technologies:** Python, TensorFlow, Keras, scikit-learn

### 3. [Traineeship Management System](Traineeship-Management-System/)
A web application developed with Spring Boot for managing university traineeships, including student applications, position assignments, and evaluations.

**Technologies:** Java, Spring Boot, Spring Security, Thymeleaf, MySQL
