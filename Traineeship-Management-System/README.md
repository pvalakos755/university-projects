
# Traineeship Management System

A university project developed using Java and Spring Boot, focused on managing student traineeships.

## Project Overview

The application is designed to facilitate the management of university traineeship positions, connecting students, companies, professors, and the traineeship committee.

## Main Features

- User registration, authentication, and role-based access.
- Management of student, company, and professor profiles.
- Creation and management of traineeship positions.
- Student applications and traineeship assignments.
- Supervisor allocation based on different selection strategies.
- Traineeship progress tracking and evaluations.

## Technologies

- Java
- Spring Boot
