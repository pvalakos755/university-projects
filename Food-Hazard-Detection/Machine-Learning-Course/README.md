
# Machine Learning Course Projects

Two academic team projects developed as part of the Machine Learning course at the University of Ioannina.

## Project 1: Image Classification

Binary image classification into "pleasant" and "unpleasant" categories.

- Used ResNet50 for feature extraction.
- Implemented and compared KNN, SVM, ensemble methods, neural networks, and CNNs.
- Evaluated models using cross-validation and classification metrics.

## Project 2: Dimensionality Reduction & Clustering

Exploration of dimensionality reduction and clustering techniques on image data.

- Applied PCA, Locally Linear Embedding (LLE), and autoencoders.
- Implemented K-Means and Agglomerative Clustering.
- Evaluated clustering performance using metrics such as Silhouette Score and Purity.

## Technologies

Python, Jupyter Notebook, TensorFlow/Keras, scikit-learn, NumPy, pandas, Matplotlib.
